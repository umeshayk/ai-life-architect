# Dashboard Patterns — AI Life Architect

## Purpose
Defines exact dashboard layout patterns.

---

# 1. Standard Dashboard Layout

## Structure

1. Page Header
2. KPI Row
3. Action Section (important)
4. Secondary Sections

---

# 2. KPI Row

- 3–5 KPI cards
- compact height
- equal width

Examples:
- Active Goals
- Overdue Tasks
- Projects at Risk
- Routines Due

---

# 3. Action Section (MOST IMPORTANT)

Must include:
- overdue tasks
- alerts
- recommendations

This section is priority over static info.

---

# 4. Secondary Sections

- Recent activity
- Upcoming events
- AI insights
- Summary charts (optional)

---

# 5. Layout Rules

Desktop:
- 2 or 3 column layout

Tablet:
- 2 column

Mobile:
- single column

---

# 6. Do NOT do

- large empty cards
- static descriptive content
- repeating same card design everywhere

---

# 7. Admin Dashboard

Separate page:
- system health
- jobs
- logs
- ingestion failures
- AI usage

Do NOT mix with user dashboard
